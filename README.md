# Mindani

A Minecraft-inspired voxel adventure game built with Godot 4 + C#, made for Lindani.

Built on [Zylann's Voxel Tools](https://github.com/Zylann/godot_voxel) for terrain and block mechanics.

## Stack

- Godot 4 (.NET / C#)
- Voxel Tools (GDExtension)
- Target platform: Android

## Project structure

```
mindani/
├── scenes/        # Godot scenes (.tscn)
├── scripts/       # C# game logic
├── assets/        # Textures, audio, models
│   ├── blocks/
│   ├── characters/
│   └── ui/
└── addons/        # Voxel Tools GDExtension
```

## Getting started

1. Open the project in Godot 4 (.NET build)
2. Enable the Voxel Tools plugin under Project → Project Settings → Plugins
3. Build and run
